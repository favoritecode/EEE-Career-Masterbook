\# Purpose



This document defines the official folder and file structure of the EEE Career Masterbook project.



Every contributor and AI assistant must follow this structure.



Do not create unnecessary folders or files.



Keep the project clean, organized and scalable.



\---



\# Root Structure



EEE Career Masterbook/



│



├── 00\_Project/



├── 01\_Volume\_Electrical\_Fundamentals/



└── 99\_Final\_PDF/



\---

Contains all project documentation.

Each volume follows the same structure.



Example

\---



\# Chapter Structure



Every chapter follows the same folder structure.



Chapter-01\_Introduction\_to\_Electricity/



│



├── Chapter-01.md



├── References.md



├── Videos.md



├── MCQ.md



├── Viva.md



└── Images/



\---



\# Assets Folder



Store reusable resources only.



Examples



Book Icons



Diagrams



Illustrations



Templates



Logos



\---



\# Images Folder



Store only images used in the current chapter.



Avoid mixing images from different chapters.



\---



\# Final PDF



Store only released PDF versions.



Example



99\_Final\_PDF/



│



├── Volume-01.pdf



├── Volume-02.pdf



└── Complete-Edition.pdf



\---



\# Expansion Policy



Complete one volume first.



Then create the next volume.



Do not create empty folders for future volumes.



The project should grow naturally.



\---



\# File Management Rules



Every file must have a clear purpose.



Never duplicate content.



Keep everything organized.



Delete unused files.



Archive released versions only.



\---



\# Backup Policy



Keep regular backups of the project.



Before major updates,



create a backup copy.



Never overwrite important project files accidentally.



\---



\# Future Growth



The project structure should support



New Volumes



Premium PDF



Website



Future Mobile App



Without changing the root structure.



\---



\# Final Rule



A clean project structure saves development time.



If a folder or file has no purpose,



do not create it.
