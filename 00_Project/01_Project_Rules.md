\# Purpose



This document defines the official rules of the EEE Career Masterbook project.



Every contributor, AI assistant and future editor must follow these rules.



\---



\# Project Mission



Build the most practical and professional EEE career guide for:



• B.Sc. EEE Students



• Fresh Graduates



• Job Seekers



• Junior Engineers



The objective is not to create the biggest engineering book.



The objective is to create the most useful engineering career guide.



\---



\# Core Principles



• Strong Fundamentals



• Career Focus



• Practical Knowledge



• Interview Ready



• Industry Oriented



\---



\# Writing Rules



Always



✓ Explain concepts clearly.



✓ Use simple Bengali.



✓ Keep technical terms in English.



✓ Give practical examples whenever useful.



✓ Focus on understanding instead of memorization.



Never



✗ Copy content from books or websites.



✗ Add unnecessary theory.



✗ Increase page count unnecessarily.



✗ Repeat the same explanation.



\---



\# Content Priority



Priority 1

Priority 2

Priority 3



Written Job Examination



Priority 4

Priority 5

\---



\# Golden Rule



Before adding any content, ask:



"Will this content help the reader become a better engineer or perform better in examinations, interviews or engineering jobs?"



If the answer is No,



Do not include it.



\---



\# PDF Philosophy



The PDF should be concise.



Detailed discussions,



extra examples,



extended theory,



animations,



and videos



should be provided through the Favorite Web website.



The PDF should remain easy to revise before exams and interviews.



\---

Professionally Written
