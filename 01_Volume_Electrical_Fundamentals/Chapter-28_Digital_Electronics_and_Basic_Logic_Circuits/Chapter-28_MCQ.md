\### MCQ-001

\*\*Question\*\*

Which type of system represents information using discrete levels?

A. Digital system
B. Purely analog system
C. Mechanical system only
D. Hydraulic system only

\*\*Answer\*\*

\*\*A. Digital system\*\*

\*\*Explanation\*\*

A Digital system commonly represents information using two discrete Logic levels, 0 and 1.

\*\*Why Not Others?\*\*

\- B uses continuously varying quantities.
\- C is not necessarily an information-representation system.
\- D does not define Digital operation.

\*\*Remember\*\*

Digital signals use discrete values.

\### MCQ-002

\*\*Question\*\*

Which statement correctly compares Analog and Digital signals?

A. Analog signals vary continuously, while Digital signals have discrete levels
B. Both signals always have only two levels
C. Digital signals vary continuously without steps
D. Analog signals can never represent physical quantities

\*\*Answer\*\*

\*\*A. Analog signals vary continuously, while Digital signals have discrete levels\*\*

\*\*Explanation\*\*

Temperature and sound are naturally continuous, whereas a Digital circuit represents sampled information through defined Logic levels.

\*\*Why Not Others?\*\*

\- B is true only for basic Binary Digital signals.
\- C describes an Analog signal.
\- D is false because Analog signals commonly represent physical quantities.

\*\*Remember\*\*

Analog = continuous; Digital = discrete.

\*\*Question\*\*

What is the Decimal equivalent of Binary 1011₂?

B. 10
C. 12
D. 13

\*\*Answer\*\*

\*\*A. 11\*\*

\*\*Explanation\*\*

\*\*Why Not Others?\*\*

\- B equals Binary 1010₂.
\- C equals Binary 1100₂.
\- D equals Binary 1101₂.

\*\*Remember\*\*

Use positional weights 8, 4, 2 and 1 for a four-bit Binary number.

\### MCQ-017

\*\*Question\*\*

Which expression demonstrates the Boolean Idempotent Law?

A. A + A = A
B. A + 1 = 1
C. A + A̅ = 1
D. A + 0 = A

\*\*Answer\*\*

\*\*A. A + A = A\*\*

\*\*Explanation\*\*

The Idempotent Law states that repeating the same variable in an OR or AND operation does not change it: A + A = A and A·A = A.

\*\*Why Not Others?\*\*

\- B is the Domination Law.
\- C is the Complement Law.
\- D is the Identity Law.

\*\*Remember\*\*

Repeating the same Boolean variable adds no new condition.
