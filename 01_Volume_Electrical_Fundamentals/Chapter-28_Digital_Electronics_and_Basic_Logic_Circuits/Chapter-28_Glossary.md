\# Chapter 28

\# Glossary

\## Digital Electronics and Basic Logic Circuits

\---

\## Digital Electronics

The branch of Electronics that represents and processes information using discrete signal levels.

\*\*Symbol\*\*: —

\*\*Unit\*\*: Not applicable

\---

\## Analog Signal

A signal whose value varies continuously with time within an operating range.

\*\*Symbol\*\*: —

\*\*Unit\*\*: Depends on the represented quantity

\---

\## Digital Signal

A signal represented by defined discrete levels, commonly Binary Logic 0 and Logic 1.

\*\*Symbol\*\*: —

\*\*Unit\*\*: Not applicable

\---

\## Logic Level

A defined Voltage range interpreted by a Digital circuit as a particular Logic state.

\*\*Symbol\*\*: 0 or 1

\*\*Unit\*\*: Volt (V) for the physical signal

\---

\## Bit

The smallest unit of Binary information, having a value of either 0 or 1.

\*\*Symbol\*\*: b

\*\*Unit\*\*: bit

\---

\## Byte

A group of eight bits commonly treated as one Digital information unit.

\*\*Symbol\*\*: B

\*\*Unit\*\*: byte

\---

\## Number System

A method of representing numerical quantities using a defined set of symbols and positional rules.

\*\*Symbol\*\*: —

\*\*Unit\*\*: Not applicable

\---

\## Radix

The number of distinct digits used by a positional Number System.

\*\*Symbol\*\*: r or base

\*\*Unit\*\*: Dimensionless

\---

\## Decimal Number System

A positional Number System with radix 10 and digits 0 through 9.

\*\*Symbol\*\*: Base 10 or subscript 10

\*\*Unit\*\*: Not applicable

\---

\## Binary Number System

A positional Number System with radix 2 and digits 0 and 1.

\*\*Symbol\*\*: Base 2 or subscript 2

\*\*Unit\*\*: Not applicable

\---

\## Octal Number System

A positional Number System with radix 8 and digits 0 through 7.

\*\*Symbol\*\*: Base 8 or subscript 8

\*\*Unit\*\*: Not applicable

\---

\## Hexadecimal Number System

A positional Number System with radix 16 and symbols 0 through 9 and A through F.

\*\*Symbol\*\*: Base 16 or subscript 16

\*\*Unit\*\*: Not applicable

\---

\## Most Significant Bit

The bit with the greatest positional weight in a Binary number.

\*\*Symbol\*\*: MSB

\*\*Unit\*\*: Not applicable

\---

\## Least Significant Bit

The bit with the smallest positional weight in a Binary number.

\*\*Symbol\*\*: LSB

\*\*Unit\*\*: Not applicable

\---

\## Binary Arithmetic

Arithmetic operations performed on Binary numbers using digits 0 and 1.

\*\*Symbol\*\*: —

\*\*Unit\*\*: Not applicable

\---

\## Carry

A bit transferred to the next higher positional column when an addition result exceeds one bit.

\*\*Symbol\*\*: C or C_out

\*\*Unit\*\*: Not applicable

\---

\## Borrow

A Binary indication that a subtraction column requires one unit from the next higher position.

\*\*Symbol\*\*: B or B_out

\*\*Unit\*\*: Not applicable

\---

\## Binary Coded Decimal

A code that represents each Decimal digit separately by a four-bit Binary pattern.

\*\*Symbol\*\*: BCD

\*\*Unit\*\*: Not applicable

\---

\## Gray Code

A non-weighted Binary code in which adjacent code values differ by only one bit.

\*\*Symbol\*\*: GC

\*\*Unit\*\*: Not applicable

\---

\## Logic Gate

An electronic circuit that performs a Boolean operation on one or more Logic inputs.

\*\*Symbol\*\*: —

\*\*Unit\*\*: Not applicable

\---

\## AND Gate

A Logic Gate whose output is 1 only when all required inputs are 1.

\*\*Symbol\*\*: Y = A·B

\*\*Unit\*\*: Not applicable

\---

\## OR Gate

A Logic Gate whose output is 1 when at least one input is 1.

\*\*Symbol\*\*: Y = A + B

\*\*Unit\*\*: Not applicable

\---

\## NOT Gate

A single-input Logic Gate that produces the complement of its input.

\*\*Symbol\*\*: Y = A̅

\*\*Unit\*\*: Not applicable

\---

\## NAND Gate

A Logic Gate that produces the complement of an AND operation.

\*\*Symbol\*\*: Y = overline(A·B)

\*\*Unit\*\*: Not applicable

\---

\## NOR Gate

A Logic Gate that produces the complement of an OR operation.

\*\*Symbol\*\*: Y = overline(A + B)

\*\*Unit\*\*: Not applicable

\---

\## XOR Gate

A Logic Gate whose two-input output is 1 when the input values are different.

\*\*Symbol\*\*: Y = A ⊕ B

\*\*Unit\*\*: Not applicable

\---

\## XNOR Gate

A Logic Gate whose two-input output is 1 when the input values are equal.

\*\*Symbol\*\*: Y = overline(A ⊕ B)

\*\*Unit\*\*: Not applicable

\---

\## Universal Gate

A Gate type capable of implementing every Boolean function when used alone in suitable combinations.

\*\*Symbol\*\*: NAND or NOR

\*\*Unit\*\*: Not applicable

\---

\## Truth Table

A table that lists every input combination of a Logic function and its corresponding output.

\*\*Symbol\*\*: —

\*\*Unit\*\*: Not applicable

\---

\## Boolean Algebra

A mathematical system for representing and manipulating Binary Logic variables and operations.

\*\*Symbol\*\*: —

\*\*Unit\*\*: Not applicable

\---

\## Boolean Variable

A variable that normally takes one of two Logic values, 0 or 1.

\*\*Symbol\*\*: A, B, C or another letter

\*\*Unit\*\*: Not applicable

\---

\## Complement

The inverse of a Boolean value or expression, changing Logic 0 to 1 and Logic 1 to 0.

\*\*Symbol\*\*: A̅, A′ or NOT A

\*\*Unit\*\*: Not applicable

\---

\## De Morgan's Theorems

Boolean rules that transform a complemented product into a sum of complements and a complemented sum into a product of complements.

\*\*Symbol\*\*: overline(AB) = A̅ + B̅; overline(A + B) = A̅B̅

\*\*Unit\*\*: Not applicable

\---

\## Logic Simplification

The process of reducing a Boolean expression or Logic circuit while preserving its complete input-output behavior.

\*\*Symbol\*\*: —

\*\*Unit\*\*: Not applicable

\---

\## Karnaugh Map

A visual grid arranged in Gray Code order for simplifying Boolean functions by grouping adjacent cells.

\*\*Symbol\*\*: K-Map

\*\*Unit\*\*: Not applicable

\---

\## Minterm

A product term containing every input variable once, either complemented or uncomplemented, and representing one Truth Table row where a function is 1.

\*\*Symbol\*\*: m_i

\*\*Unit\*\*: Not applicable

\---

\## Combinational Logic Circuit

A Logic circuit whose present output depends only on its present input combination.

\*\*Symbol\*\*: —

\*\*Unit\*\*: Not applicable

\---

\## Half Adder

A Combinational circuit that adds two one-bit inputs and produces Sum and Carry outputs.

\*\*Symbol\*\*: HA

\*\*Unit\*\*: Not applicable

\---

\## Full Adder

A Combinational circuit that adds two one-bit values and a Carry-in and produces Sum and Carry-out.

\*\*Symbol\*\*: FA

\*\*Unit\*\*: Not applicable

\---

\## Half Subtractor

A Combinational circuit that subtracts one one-bit value from another and produces Difference and Borrow outputs.

\*\*Symbol\*\*: HS

\*\*Unit\*\*: Not applicable

\---

\## Full Subtractor

A Combinational circuit that subtracts two one-bit values while including a Borrow-in and producing Difference and Borrow-out.

\*\*Symbol\*\*: FS

\*\*Unit\*\*: Not applicable

\---

\## Multiplexer

A Data-selection circuit that forwards one selected input from several inputs to a single output.

\*\*Symbol\*\*: MUX

\*\*Unit\*\*: Not applicable

\---

\## Demultiplexer

A Data-routing circuit that forwards one input to one selected output among several outputs.

\*\*Symbol\*\*: DEMUX

\*\*Unit\*\*: Not applicable

\---

\## Select Line

A control input that determines the selected Data path in a Multiplexer or Demultiplexer.

\*\*Symbol\*\*: S, S₀, S₁

\*\*Unit\*\*: Not applicable

\---

\## Encoder

A Combinational circuit that converts an active input line into a coded Binary output.

\*\*Symbol\*\*: ENC

\*\*Unit\*\*: Not applicable

\---

\## Decoder

A Combinational circuit that interprets a Binary input code and activates the corresponding output.

\*\*Symbol\*\*: DEC

\*\*Unit\*\*: Not applicable

\---

\## Propagation Delay

The time interval between a valid input change and the corresponding valid output change in a Logic circuit.

\*\*Symbol\*\*: t_pd

\*\*Unit\*\*: Second (s), commonly nanosecond (ns)

\---

\## Noise Margin

The maximum unwanted signal variation a Digital Logic level can tolerate without being interpreted incorrectly under specified conditions.

\*\*Symbol\*\*: NM

\*\*Unit\*\*: Volt (V)

\---

\# End of Chapter 28 Glossary
